# Deeper Siri integration (Ask Persona, personal Agents, calling Persona, Control Center)

Building on `docs/apple/intents.md` (Ask Claude / status / approve first / open session), this adds Siri entry points for the assistant and personal Agents. Every intent connects directly to the hub in the background:
it reads `Keychain.serverConfig` afresh each time (the hub address + device token saved during pairing). The App does not need to be in the foreground, and no WebSocket is required.

## Intents

| Intent | Title | Purpose | Run mode |
| --- | --- | --- | --- |
| `AskPersonaIntent` | Ask Persona | Sends a question to the assistant's main chat (`main` from `GET /api/v1/assistant`; if none exists, opens one with `POST /api/v1/assistant/conversations` and `main:true`). Polls `items?after_seq=` for up to about 24 seconds, waits until the session is no longer working, then reads the assistant's text aloud and displays a card (question + full answer). If the answer is slow, says "Sent to Persona. It's still thinking." | Background |
| `TalkToPersonaIntent` | Talk to Persona | Starts a duplex voice chat when Persona's voice screen is on the car's screen (`docs/apple/carplay.md`); with CarPlay connected and another app on its screen, says to open Persona there first. With no car connected it calls Persona on the phone, as Call Persona does ("Calling Persona" below); only there does its description promise the call (on Apple Vision Pro it stays CarPlay's). | Background (CarPlay); foreground for the call on the phone |
| `CallPersonaIntent` | Call Persona | Calls Persona on the main chat of the selected hub: the same call as the chat's Call, on the system's call UI, which keeps going in other apps and with the phone locked ("Calling Persona" below). | Foreground |
| `AgentTaskIntent` | Give an Agent a Task | `POST /api/v1/agents/sessions/{id}/messages`, with a new UUID for `clientId` each time (hub deduplication + outbox). Choose a session through `PersonalAgentEntity`; if none is selected, use the first in the list with `canSend`. Like the Personal Agents page and its Spotlight index, it uses the App's currently selected hub group (`hub.group`; the first group if it is missing). | Background |
| `AgentsStatusIntent` | Personal Agent Unread | `GET /api/v1/agents/sessions`: reports how many sessions have how many unread messages, listing the first three; if none are unread, reports the three most recent. Reads the App's currently selected hub group, as the Personal Agents page does. | Background |
| `AddTodoIntent` | New To-Do | `POST /api/v1/todos` (`{"title", "notes"?}`, see `docs/assistant/todos.md`), in the App's currently selected hub group (`hub.group`, the same as the To-dos page; falls back to the first group if it is missing). Reads "To-do saved: '…'" and returns the title for use in subsequent Shortcuts actions. If an old hub lacks the to-do endpoint (404), asks the user to update the hub first. | Background |
| `OpenPersonalAgentIntent` | Open Personal Agent | Tapping a personal Agent session in Spotlight opens that conversation directly (Agents › Personal Agents › session; back goes to the personal Agents list; an open settings sheet is closed first). `AppModel.openPersonalAgent` is handed to `ChatsView`, which, as with `openChat`, pushes it once the list has appeared and the navigation stack is still. | Foreground |
| `OpenPersonaAssistantIntent` / `OpenPersonaAgentsIntent` | Open Persona Assistant / Agents | Intents behind the controls for Control Center, the Lock Screen, and the Action Button. | Foreground |
| `OpenPersonaTypingIntent` | Message Persona | Opens the selected hub's main conversation with its composer's keyboard up (#17789): `AppModel.openMainAssistantForTyping` closes Settings' sheet, picks the Persona tab, opens the main conversation and sets `composerFocus` to it. The composer takes that request through `tabActiveTask` once the chat is in front and the app active, retrying briefly until the field is first responder (a cold launch lays it out before it can be). A cold launch waits at most 8 s for the hub's main conversation; with none (a fresh install) it opens the new conversation page instead, without the keyboard. An App Shortcut on the iPhone and the intent of `MessagePersonaControl`. | Foreground |
| `OpenPersonaDictationIntent` | Dictate to Persona | Opens a new assistant conversation and leaves its visible starter a one-shot request to start the composer's existing dictation. Permission or availability failure keeps the new conversation, focuses the field and shows the mic's usual message; nothing is sent automatically. | Foreground |
| `OpenPersonaCallIntent` | Call Persona | Behind the Call Persona control (#13241): `CallPersonaIntent.place()`, the same call as Call Persona's. Not discoverable, so Shortcuts lists Call Persona once (the App Shortcut). | Foreground |
| `StartMeetingRecordingIntent` | Record (Record a Meeting until #5243; the type keeps its name, so shortcuts made with it keep working) | Starts a meeting recording on the phone, named after the calendar event happening now, with its Live Activity (Stop, Bookmark); does nothing while something already records. An `AudioRecordingIntent`: no hub needed, the transcript syncs later (`docs/apple/recording.md`, "Meeting recordings"). | Background (foreground once, to ask for the microphone) |

`PersonalAgentEntity` is an `IndexedEntity`: whenever the Agents page finishes loading, it calls `CSSearchableIndex.default().indexAppEntities(...)`
and `PersonaShortcuts.updateAppShortcutParameters()`, so Spotlight can find sessions and Siri phrases containing session names can match them.

## Phrases (`PersonaShortcuts`, available immediately after installation, no manual setup)

- Ask Persona: "问 Persona" (Ask Persona), "用 Persona 问一下" (Ask with Persona), "Ask Persona", "Ask Persona a question" → Siri then asks "What do you want to ask Persona?"
- Give an Agent a Task: "用 Persona 让 Agent 去做" (Have Persona give an Agent a task), "让 Persona 的 <会话名> 去做" (Have Persona's <session name> do it), "Persona 交给 Agent" (Persona, hand it to an Agent), "Have Persona agent do something", "Send a task to <session name> with Persona"
- Personal Agent Unread: "Persona 个人 Agent 未读" (Persona personal Agent unread), "Persona Agent 有什么新消息" (What's new from Persona Agents), "Check Persona agents"
- New To-Do: "用 Persona 新建待办" (Create a to-do with Persona), "Persona 记个待办" (Persona, note a to-do), "Persona 加个待办" (Persona, add a to-do), "Add a to-do in Persona", "New Persona to-do" → Siri then asks "What's the to-do?"; notes can only be entered in the Shortcuts App.
- Call Persona (#9290): "打给 Persona" (Call Persona), "和 Persona 通话" (Start a call with Persona), "给 Persona 打电话" (Give Persona a call), "用 Persona 打电话" (Make a call with Persona), "打电话给 Persona" (Phone Persona), "Persona 通话" (Persona call); in Japanese "Personaに電話", "Personaと通話を始めて", "Personaに電話をかけて", "Personaで電話して", "Personaに電話して", "Personaで通話". iPhone only. Siri may take a "call <name>" phrase as a phone call of its own: the Simulator's Siri answered "Call Persona" and "Start a call with Persona" with "Sorry, I can't make a phone call with your iPhone" (it runs no App Shortcut at all, Talk to Persona included), so on a phone check which phrases reach Persona ("Verification on a phone" below); "Persona call" leads with the name.
- Start Meeting (Record until #8731): "用 Persona 开会" (Start a meeting with Persona), "Persona 开始会议" (Persona, start a meeting), and the earlier "用 Persona 录音" (Record with Persona), "用 Persona 录会议" (Record a meeting with Persona), "用 Persona 录下这个会" (Record this meeting with Persona), "在 Persona 开始录音" (Start recording in Persona), "Persona 录会议" (Persona, record the meeting). Every one records a meeting (`docs/apple/recording.md`, "Meeting recordings").
- Message Persona (#17789, iPhone only): "Type to Persona", "Write to Persona", "Open my Persona chat", "Open the keyboard in Persona" (zh-Hans and ja in `AppShortcuts.xcstrings`). No "Message Persona" phrase: Siri takes "Message <name>" as a text message of its own.
- Apple allows ten App Shortcuts, and the iPhone's list is full: Call Persona (#9290) took Run Extension Action's place there, and Message Persona (#17789) took Ask Claude's (an Agents-side action; on the iPhone it stays an action in the Shortcuts app, without a phrase). That one asks which action and can't take its values by voice, so on the iPhone it is an action in the Shortcuts app (and the Action button through a shortcut of your own), without a phrase; Apple Vision Pro keeps its phrase. `CallPersonaIntentTests.atMostTenAppShortcuts` holds the count. `PersonaShortcuts` is one list per platform with no `#if` inside the builder: the metadata extractor silently drops an App Shortcut inside one, so until #17789 the iPhone registered neither Call Persona nor Start Meeting (`docs/lessons/ios.md`, "An App Shortcut inside `#if` is never registered"); `MessagePersonaIntentTests.theBuiltMetadataListsEveryAppShortcut` checks the built app's metadata.
- **Log Water** (#13274, `apple/Shared/LogWaterIntent.swift`) is a Shortcuts action on iPhone, iPad, Apple Watch and Apple Vision Pro, with optional millilitres (empty means one glass). It runs in the background and reads back the recorded amount and today's progress. It is not added to `PersonaShortcuts`: all ten slots remain taken. Create your own shortcut containing Log Water, then say its name to Siri or choose it under Settings › Action Button › Shortcut. See `docs/apple/intents.md` ("Log Water (#13274)").
- The existing Ask Claude / status actions each gain an English phrase.

`String` parameters cannot appear in phrases (see `docs/apple/intents.md`), so Siri asks for the question / task contents after the invocation phrase.

## Calling Persona (#9290)

A call to Persona from Siri is the same call as the chat's Call: `PersonaCalls.shared.callPersona(origin: .siri)` on the selected hub's main conversation, with the same refusals (an urgent call, a recording, no hub, no voice extension, the microphone) and the same call page. There are three ways in from Siri, and the Call Persona control places the same call (Control Center below).

Whatever page or sheet the app was left on (Settings' sheet included), the call page comes up over it in the call's own window (`CallWindow`; `docs/design/DESIGN_SYSTEM.md`, "Call screen"), closing nothing, and a refusal says why in the voice alert there. Minimize goes back to that page, with the bar at the top that returns to the call over it.

- **Call Persona** (`CallPersonaIntent`, an App Shortcut: no entitlement, nothing to set up). "Hey Siri, call Persona" (AirPods included), the Shortcuts app, Spotlight and the Action button. It runs in the foreground (`supportedModes .foreground(.immediate)`): the system takes a call's Start only from an app in front, and the call page shows there. Siri says "Calling Persona" and the page appears in "Calling…" at once. The Start waits until the app is active (`PersonaCalls.place` for any origin but `.app`), because one started while the app is still coming to the front is refused (LiveCommunicationKit's code 6), and is tried once more half a second later if it still is. A cold launch also waits (at most 8 s) for the hub links and the main conversation first.
- **Talk to Persona with no car**: with CarPlay not connected, `TalkToPersonaIntent` comes to the front (`continueInForeground`, it is `[.background, .foreground(.dynamic)]`) and places the same call. With Persona's voice screen in the car it is the car's voice chat as before, in the background (the phone may stay locked in the car). With CarPlay connected but another app on its screen it still says to open Persona there: a call that needs the phone unlocked is the wrong answer while driving (`CarPlayTalk.callsOnThePhone`). "No car" is not "no CarPlay scene of Persona's": Persona has one only once it was opened on the car's screen since it launched (Siri may just have launched it, with Maps on the car's screen), and only with its CarPlay entitlement. Without one, the phone's audio route answers whether a car is there (`CarPlayVoicePresence.talkNow`: an output of type `carAudio`, read off the main actor), and a car means "open Persona on the car's screen", never a call.
- **"Call Persona using Persona"** (SiriKit `INStartCallIntent`), **opt-in, off by default** (config.json `app.siri_calls`, `docs/operations/config.md`). The app is single-scene, and SiriKit asks an app itself for a handler only when it supports multiple scenes, so the intent needs an Intents extension (`apple/PersonaCallIntents/`, merged in by `apple/siri-calls.yml`) with its own App ID and profile, and the app needs the Siri entitlement with `SIRIKIT` on its App ID: account work for the maintainer (`docs/operations/release.md`, "Siri calls"). The extension resolves whoever was named to the one person there is, Persona (handle "Persona", the product's name: the extension cannot read which look the app shows, while the app's own calls carry the assistant's name; any handle calls the same main conversation), says the call is a voice call, and answers `.continueInApp`: Siri opens the app with an `INStartCallIntent` user activity, which places the call as a redial from Recents does (`PersonaCalls.continueActivity`). It never starts a call itself (Apple says not to). Siri uses it only once Persona may use Siri: a build with the switch asks once (`SiriCalls.askOnce`), when the app becomes active with a hub paired and no call on; the purpose string is `NSSiriUsageDescription`. Siri's example phrases are in `AppIntentVocabulary.plist` in en, zh-Hans and ja (App Store Connect refuses SiriKit intents without them, ITMS-90626). Only `INStartCallIntent`, which replaced the deprecated `INStartAudioCallIntent` in iOS 13 (the app still takes either from Recents). Because `SiriCalls.swift` and `OwnerCall.swift` unconditionally compile into the iOS app and link `Intents`, `NSSiriUsageDescription` (with its translations in `InfoPlist.xcstrings`) stays in `apple/project.yml` and `apple/Persona/Resources/Info.plist` in every build so App Store Connect does not reject uploads with ITMS-90683; with the switch off, the extension, Siri entitlement, `PersonaSiriCalls` flag, signing preflight and runtime Siri authorization prompt stay off. On, no tracked file is rewritten (the app signs with a generated `apple/PersonaSiriCalls.entitlements`, and `PersonaSiriCalls` goes into the built Info.plist).

On a locked phone every way asks for Face ID or the passcode first: the call needs the app in front, and Apple asks for the unlock on purpose for calls Siri starts (AirPods included; DTS: "to minimize the possibility of the user inadvertently triggering calls"). The call itself then goes on with the phone locked. CarPlay's Siri call screen is not used: CarPlay asks VoIP calling apps for CallKit and the CarPlay communication entitlement, which Persona doesn't have; the car keeps Talk to Persona.

## Action Button and Control Center

- Action Button: **Settings › Action Button › Shortcut**; select "Message Persona", "Ask Persona", "Give an Agent a Task", "New To-Do", "Start Meeting" or "Call Persona" directly (App Shortcuts appear automatically), or **Controls** › Persona › Message Persona, Dictate to Persona, Call Persona, Ask Persona or Record.
- What each press opens, as ChatGPT's iOS app does for its Dots (message / dictate / call, each a Shortcuts action the Action button can run): Message Persona the main chat with the keyboard up; Dictate to Persona a new conversation with dictation running; Call Persona a call on the main chat.
- Control Center / Lock Screen: the `PersonaWidgets` extension adds `ControlWidget`s: `AskPersonaControl`, `PersonaAgentsControl` open the App's assistant page / Agents page;
  `MessagePersonaControl` (kind `persona.control.message`, keyboard glyph) opens the main chat with the keyboard up, as Message Persona does (#17789);
  `DictatePersonaControl` (kind `persona.control.dictate`) opens a new assistant conversation with dictation running once its composer is visible;
  `CallPersonaControl` (kind `persona.control.call`, Call Persona's glyph) calls Persona on the main chat, as Call Persona does (#13241);
  `MeetingRecordingControl` (kind `persona.control.meeting-recording`) starts a meeting recording without opening the App.
  Their intents live in `LiveActivity/PersonaControlIntents.swift` and `LiveActivity/RecordingIntents.swift` (compiled into both App and extension; `perform` runs only in the App).

## Not implemented / deferred

- Apple Intelligence assistant schemas such as `@AppIntent(schema: .assistant...)`: none fits "ask a private assistant" (existing schemas cover domains such as mail / photos / books), so they are not integrated.
- A personal Agent's Spotlight result carries no hub group: with several hub groups connected, the opened conversation uses the App's selected group, and a session in another group shows an error on its page.
- Ask Persona has a 24-second answer limit: long tasks cannot be read in full; view them in the App's main chat.
- For long chats in the car, see `docs/apple/carplay.md` (Siri is only the entry point; the chat uses duplex voice).
- Controls other than Record can only open the App. Asking directly from a control would require App Intents text input, which controls do not support.

## Verification on a phone

1. After installing through TestFlight / Xcode, open the App once (and pair it), then visit **Agents › Personal Agents** once so sessions are indexed.
2. Say "Ask Persona" to Siri, then ask a question: it should read the answer and show the full text on a card; the App's main chat should contain this turn.
3. Say "Have Persona agent do something", choose a session, and describe the task: it should reply "Sent to '…'"; that session in the Lark gateway should receive the message. The same task must not be duplicated (clientId).
4. Say "Check Persona agents".
5. Say "Add a to-do in Persona", then give a title: it should reply "To-do saved: '…'", and the App's To-dos page should contain the new entry.
6. These actions should appear under **Shortcuts App › Persona** and be selectable for the Action Button; **Control Center › Add a Control › Persona** should contain Ask Persona, Persona Agents, Message Persona, Dictate to Persona and Call Persona. Message Persona, from the Action button (as a shortcut and as a control) with Persona not running, in the background and left on another tab, opens the main chat with the keyboard up. Dictate opens a new conversation with its dictation bar up; after stopping, the recognized words stay as an unsent draft. Call Persona, pressed from Control Center and from the Lock Screen with the phone locked (Face ID first), opens the app and starts the same call as saying "Call Persona".
7. Searching for a personal Agent's session name in Spotlight should find it; tapping it opens that conversation directly, and back in the top-left returns to the personal Agents list. Try once each with the settings sheet open, with the App in the background, and with it not running.

8. Calling Persona: with the phone unlocked and Persona in the background, say "Call Persona" (then each other phrase, in each language): the call page appears in "Calling…" and the call connects (note any phrase Siri takes as a phone call of its own); switch apps and lock the phone, and it goes on. Say "Talk to Persona" with no car connected: the same call. With the phone locked, both ask to unlock first (with AirPods too). In a build with `app.siri_calls`, allow Siri once when Persona asks, then say "Call Persona using Persona" (and "用 Persona 打给 Persona", "PersonaでPersonaに電話して" in those languages): Siri hands it to Persona and the same call starts.
