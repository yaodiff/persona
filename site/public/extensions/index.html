装个扩展，
它就多一样本事。

数据源、工具、新页签、渠道和 Agent 运行时，都能做成扩展。这里是官方维护的全部扩展，可以按名字、功能和标签找；要什么权限，装的时候都会写清楚。

怎么装

  1. 打开 Persona App，或者 hub 上的网页版
  2. 进「设置 → 扩展 → 扩展市场」
  3. 搜扩展的名字，点安装

市场里没有它们的话（旧版本 hub），先添加这个市场地址：

github:nwverse/persona-extensions
